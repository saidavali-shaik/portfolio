# Saidavali Portfolio — video-style layout

This version changes the hero to the same pattern as the reference video:
**large name on the left + centered portrait + role on the right**, followed by a horizontal scrolling skills line.

## Run
Open `index.html` with VS Code Live Server.

## Personalize
- Replace `profile.jpg` with your original portrait for better quality.
- Change `yourmail@example.com`.
- Replace GitHub and LinkedIn URLs.
- Replace the project links with your repositories.
